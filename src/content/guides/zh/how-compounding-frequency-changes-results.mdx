两个都宣传“7%”的账户不一定是同一种账户。名义利率是一个数字，而复利计算频率决定这个数字最终会产生什么结果。

一年下来的差额很小。三十年下来的差额则并非如此，值得理解背后的计算，而不是靠估算。

## 计息频率为何重要

其机制是一种时间差。每月计入的利息早于每年计入的利息，而提前计入的利息有更长时间继续产生利息。

具体来说：按年复利计算，全年利息会在年末一次性计入。按月复利计算，全年利息的十二分之一会在每月末计入，并立即开始产生利息。额外利息虽然不多，但会产生很长时间。

## 实际年利率

比较两种计息频率的方法是使用实际年利率：即在一年内产生相同结果的利率，与按所述频率复利的利率相同。

**EAR = (1 + r)ⁿ − 1**

其中 **r** 是名义年利率除以每年的期数，**n** 是每年的期数。

按 7% 计算：
| 频率 | 实际年利率 |
|---|---|
| 每年 | 7.000% |
| 每年两次 | 7.122% |
| 每四个月 | 7.165% |
| 每季度 | 7.186% |
| 每两个月 | 7.207% |
| 每月 | 7.229% |

这个序列是单调的，而且随着频率增加，步长会变小，这正是实际意义所在：第一次提高计息频率带来的收益，大于最后一次提高。

本网站的<a href="/zh/tools/compound-interest/">复利计算器</a>直接计算实际利率，并在结果中与名义利率并列显示，以便比较两者。

## 会有多大差异

更有用的看法是比较总额，而不是利率。

$10,000 按 7% 存一年，按月复利可得到 $10,722.90，按年复利则为 $10,700.00。差额是 $22.90，单凭这一点不值得作出决定。

在三十年内不再追加投入的情况下，同样的 $10,000 按月复利会变成$76,123，按年复利会变成 $75,624，差额为 $499。在同一期间每月投入
$500 时，两个余额及其差额都会大幅增加，因为这些投入本身也在按更高的实际利率获得利息。

这一规律始终一致：两种频率之间的差距在最初几年较小，随后会稳定扩大，因为这个差距本身也在产生复利。

## 为什么此工具提供六种频率

该工具提供每年、每年两次、每四个月、每季度、每两个月和每月这几种选项。原因是这里的投入按月进行，而计算过程会让复利周期与投入周期保持一致。

任何能整除十二的频率都能让这项计算保持精确，而不是近似。不能整除十二的频率则需要将一笔缴款分摊到两个复利期，这会引入一种舍入约定，而它是模型的产物，而不是产品本身的特征。

## 这不是什么

这是对两种信用条款的比较，而不是对两种产品的比较。两个账户即使名义利率相同、计息频率相同，也可能大不相同，原因在于费用、最低余额、提款限额，以及该账户在税务上的处理方式。

Investor.gov 关于费用与支出以及账户类型的页面介绍了这些差异。美联储的 H.15
系列记录了储蓄产品实际支付的利率，可用于核查所报利率是否处于合理范围。

## 一个实用的检验方法

从 H.15
系列中取一个利率，将其输入计算器，分别按年度复利和按月复利计算，然后查看最终余额的差额。这个差额就是更高频计息带来的价值，它是一个数字，而不是一条经验法则。
